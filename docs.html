1 · THE SEAL

A seal is a 7-character code derived from three things: the ticker, the founder's X handle and the lore text. It is computed with FNV-1a, a 32-bit non-cryptographic hash, and it is deliberately small enough to read aloud.

THE KEY

TICKER|handle|the lore text, exactly as written

The ticker is uppercased, the handle is lowercased with any leading @ stripped, and the lore is untouched — every space and line break counts.

THE FUNCTION

function fnv(str){
  let h = 0x811c9dc5;
  for (let i = 0; i < str.length; i++){
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h >>> 0;
}

function sealOf(tick, handle, lore){
  const key = tick.toUpperCase().trim() + '|'
            + handle.replace(/^@/, '').toLowerCase().trim() + '|'
            + lore;
  return 'LORE-' + fnv(key).toString(36).toUpperCase().padStart(7, '0').slice(-7);
}

WHY NOT SHA-256

Because you should be able to compute this by hand, in any language, in about a minute. The seal is a tamper-evidence check, not a security primitive — the chain is what makes it binding. Its only job is to make an edit obvious to somebody who was not there.

Collisions exist in a 32-bit space. They do not help an attacker here: to forge a seal you would have to produce different lore that hashes the same and reads as a plausible story for the same ticker and handle. If that ever mattered at scale the key can be widened without changing anything else.

3 · THE SPLIT

Pons takes 1.00% of every trade. That is the protocol's own fee, not something LOREPAD adds. It is split 70 / 30 between the creator and Pons, so 0.70% is the part the pad controls and 0.300% never reaches us.

WORKED

At $1,000,000 of 24h volume, Pons collects $10,000. The creator share is $7,000 — $2,100 to the scribe and $4,900 into the vault. The pad has a slider so you can move the split and watch every number move with it before you spend anything.

THE VAULT

Paid out to holders in the stock the coin is paired to. Six choices at launch: SPY, NVDA, TSLA, META, NFLX, COIN. Prices are read live — if one is missing, the page says so rather than guessing at it.

THE SCRIBE SHARE

Escrowed from the first trade and claimed by posting the seal from the handle it was signed with. Because the seal is derived from the handle, anyone can check the claim without trusting us. Unclaimed, it stays escrowed — it does not come back to the pad.
